# BasicsOfPython

This folder contains assignments and examples for basic Python concepts, including exception handling, modules, packages, control flow, data structures, file handling, and functions.

## Python Files:
- `exception_handling_assignment.py`: Demonstrates exception handling in Python with examples including safe division (handling division by zero and type errors), bill calculation with invalid price handling, age validation with custom exceptions, and file reading with error handling.

## Notebooks:
- `control_flow_assignment.ipynb`: Jupyter notebook containing exercises on control flow statements like if-else, loops, etc.
- `data_structures_assignments.ipynb`: Notebook with assignments on Python data structures such as lists, dictionaries, tuples, etc.
- `file_handleing_assignment.ipynb`: Notebook demonstrating file handling operations in Python (note: filename has a typo, should be 'handling').
- `functions_assignment.ipynb`: Notebook with exercises on defining and using functions in Python.

## Subfolders:
- `modules_assignments/`: Contains examples of Python modules and packages.
  - `main.py`: Main script that imports and demonstrates usage of custom modules (Math_utils, string_utils) and the shop_package.
  - `Math_utils.py`: Module providing basic mathematical utility functions: add, subtract, multiply, square, and cube.
  - `string_utils.py`: Module with string manipulation functions: capitalize words, reverse string, and count words.
  - `shop_package/`: A Python package for shop-related functionalities.
    - `billing.py`: Functions to calculate total prices from a list and apply tax rates.
    - `discount.py`: Functions to apply percentage discounts or flat discount amounts to prices.

## Data Files:
- `products.txt`: Sample product data file.
- `sales_data.txt`: Sample sales data file.
- `products.txr`: Possibly a typo or alternate product file (extension .txr instead of .txt).
