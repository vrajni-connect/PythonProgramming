# modules_assignments

This folder demonstrates the use of Python modules and packages, including importing, organizing code into reusable modules, and creating packages.

## Python Files:
- `main.py`: The main script that imports functions from Math_utils and string_utils modules, as well as from the shop_package, and demonstrates their usage with example calls.
- `Math_utils.py`: A module containing basic mathematical operations: addition, subtraction, multiplication, squaring, and cubing numbers.
- `string_utils.py`: A module with string utility functions: capitalizing words, reversing strings, and counting words.
- `__init__.py`: Initialization file for the modules_assignments package (currently empty).

## Subfolders:
- `shop_package/`: A subpackage for shop-related billing and discount functionalities.
  - `billing.py`: Provides functions to calculate total prices and apply taxes.
  - `discount.py`: Offers functions to apply discounts (percentage or flat amount) to prices.
  - `__init__.py`: Initialization file for the shop_package (currently empty).
