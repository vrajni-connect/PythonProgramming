# streamlit_assignment

This folder contains assignments building web applications using the Streamlit framework for Python.

## Python Files:
- `app_basic.py`: A basic Streamlit application that displays a title, takes user name input, and greets the user upon button click.
- `app_dashboard.py`: A simple sales dashboard app allowing users to select a month and view sales data with metrics and a bar chart.
- `app_discount.py`: An application for calculating discounted prices based on original price and discount percentage, displaying results and a comparison table.
- `app_product_form.py`: A form-based app for adding products, using sidebar inputs for name, category, and price, with confirmation display.
